Clé d'accès

Les emplois du temps disent où sont les enfants : le service du NAS demande une clé. C'est celle écrite dans le fichier .env du projet « pronote » (ligne CLE_ACCES). Elle reste enregistrée sur ce téléphone.

Connecter Pronote
  1. Sur le PC, ouvre Pronote (compte parent) comme d'habitude.
  2. En haut de la page, clique sur le pictogramme QR code (« connexion à l'appli mobile »).
  3. Choisis un code à 4 chiffres : le QR code s'affiche, il est valable quelques minutes.
  4. Lis-le avec le téléphone : bouton Scanner ci-dessous si ton navigateur le permet, sinon avec Lecteur QR, puis copie le texte obtenu ici.

Aucun mot de passe n'est enregistré : Pronote donne au NAS un jeton, comme à l'appli officielle. Tu peux le révoquer dans Pronote (Mes données › Sécurisation).
