Atelier de polices

Charge les pages scannées d'une grille, règle le tracé et l'espacement en regardant l'aperçu, puis télécharge le fichier .ttf. Tout se calcule dans ton navigateur. La grille de Gaby est chargée en exemple.

1 · Pages scannées

Les fichiers remplissent les pages dans l'ordre : 1 lettres, 2 accents et signes, 3 phrases (facultative). Le quadrillage bleu doit tomber sur les cases ; sinon, un carré noir de coin n'a pas été trouvé.

2 · Réglages

Encre

Plus haut : on garde aussi les traits pâles. Trop haut : les lignes grises reviennent.

Amincit ou épaissit le feutre, en pixels du scan.

Les taches plus petites que cette surface (px²) sont effacées. Attention aux points des i.

Tracé

Adoucit les bords. Trop fort : les petites boucles se ferment.

Un point gardé tous les N pixels du contour. Petit = fidèle mais fichier plus lourd.

Espacement

Marge de chaque côté d'une lettre, en unités (1000 = hauteur de police).

Largeur de la touche espace.

Crénage

La ponctuation est limitée à la moitié, pour qu'un tiret ne rentre pas dans une lettre.

4 · Valider

Pour installer sous Windows : ferme Word, désinstalle l'ancienne version de la police si elle existe, puis clic droit sur le fichier → Installer pour tous les utilisateurs. Dans Word, active le crénage : Police (Ctrl+D) → Paramètres avancés → Crénage pour les polices.
