Ce qui prend de la place, en un coup d'œil

Qui prend toute la place ?

Choisis un dossier (ou tout ton disque) : Place nette te montre où partent les gigaoctets, les plus gros fichiers, les doublons et ce que tu peux supprimer sans risque.

📁 Analyser un dossier

Téléchargements, Documents, un disque externe… Sur ordinateur, tu peux aussi glisser un dossier sur la page.

Sur Android, choisis par exemple DCIM, Pictures, Movies ou WhatsApp : Android n'autorise pas la racine du stockage ni le dossier Download en entier. Pour la vue globale du téléphone : Paramètres → Stockage.

💽 Tout le disque C:

Un site web n'a pas le droit de lire tout ton disque. Un petit script PowerShell fait l'inventaire (rien n'est envoyé nulle part) :

  1. Copie la commande ci-dessous.
  2. Ouvre PowerShell (touche Windows, tape « PowerShell », Entrée), colle avec un clic droit, puis Entrée. Compte quelques minutes.
  3. Ouvre le rapport place-nette.txt créé sur ton Bureau — ici, ou sur ton téléphone.
Voir la commande / autre disque / Mac et Linux

Pour un autre disque, remplace C:\ par D:\ sur la 1re ligne. Lancé « en tant qu'administrateur », PowerShell voit aussi les dossiers protégés.


          
Mac (Terminal, ton dossier personnel) :

          
find ~ -type f -size +0 -exec stat -f '%z%t%Sm%t%N' -t '%Y-%m-%d' {} + 2>/dev/null > ~/Desktop/place-nette.txt

          
Linux (tout le disque système) :

          
find / -xdev -type f -printf '%s\t%TY-%Tm-%Td\t%p\n' 2>/dev/null > ~/place-nette.txt
